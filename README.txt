KONGU JOB AGENCY WEBSITE
========================

Files:
- index.html: website content and sections
- styles.css: premium blue responsive design
- script.js: mobile navigation, job filters, enquiry form
- assets/: background images and favicon

HOW TO USE WITH GITHUB PAGES
1. Extract this ZIP.
2. Open your GitHub repository.
3. Upload the contents inside the extracted folder (not the ZIP itself).
4. Keep the assets folder and its contents together.
5. Commit changes to the branch/folder configured for GitHub Pages.
6. Open the published Pages URL and test the navigation, category filters and WhatsApp enquiry.
